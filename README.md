# 📇 Smart Contact Manager

## 🚀 Overview
Smart Contact Manager is a **Spring Boot–based web application** that allows users to **securely store, manage, and organize contacts**.  
The project focuses on implementing **authentication, authorization, and role-based access control** using standard **MVC architecture** and backend best practices.

It also supports **Google OAuth2 login** for seamless and secure authentication.

---

## ✨ Key Features
- User Registration & Login using **Spring Security**
- **Google OAuth2 Login**
- **Role-Based Access Control** (USER / ADMIN)
- Add, Update, and Delete contacts
- Secure password hashing with **BCrypt**
- Custom login and registration flow
- Layered MVC architecture (Controller, Service, Repository)
- Server-side rendering with **Thymeleaf**
- Responsive UI using **Bootstrap**
